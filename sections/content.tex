\section{任务场景建模}

\subsection{封控区域}

任务场景设置为一个尺寸为 $6\,\mathrm{m}\times6\,\mathrm{m}$ 的封闭方形区域。区域地面分布有少量障碍物，四周由墙体封闭，且每侧墙体均设置一扇可供目标进出的门。

\subsection{智能体组成与初始位置}

封控系统由一台光电云台、两架无人机和一辆麦克纳姆轮式移动机器人（以下简称“麦轮车”）组成。各智能体的初始部署如下：

\begin{itemize}
    \item 光电云台固定安装于区域中心，通过持续旋转实现对区域的扫描与监视；
    \item 两架无人机和一辆麦轮车分散部署于区域角落附近，负责协同巡检与目标围捕。
\end{itemize}

\subsection{封控智能体参数}

各类封控智能体的主要参数如下：

\begin{enumerate}
    \item \textbf{光电云台}
    \begin{itemize}
        \item 姿态转动轴：横滚轴（Roll）、俯仰轴（Pitch）和偏航轴（Yaw）；
        \item 各转动轴的最大转动速度；
        \item 视场范围及目标探测距离；
        \item 在仿真环境中，采用YOLO目标检测算法识别入侵目标。
    \end{itemize}

    \item \textbf{无人机}
    \begin{itemize}
        \item 最大线速度与最大角速度；
        \item 当前线速度与当前角速度；
        \item 感知范围；
        \item 捕获半径 $r_1$。
    \end{itemize}

    \item \textbf{麦轮车}
    \begin{itemize}
        \item 最大线速度与最大角速度；
        \item 当前线速度与当前角速度；
        \item 感知范围；
        \item 捕获半径 $r_2$。
    \end{itemize}
\end{enumerate}

\subsection{智能体工作模式}

封控智能体具有以下两种工作模式：

\begin{enumerate}
    \item \textbf{巡检模式：}在未发现入侵目标时，各智能体按照预设巡检策略在责任区域内执行巡逻和搜索任务，光电云台持续扫描封控区域。
    \item \textbf{捕获模式：}任一智能体发现入侵目标后，系统将目标信息共享至其他智能体，各智能体随即由巡检模式切换至捕获模式，并协同完成目标追踪与围捕。
\end{enumerate}

\subsection{入侵目标及其任务}
入侵目标从封控区域任意一侧的门进入，并以规避封控智能体的探测和围捕为主要任务。在运动过程中，入侵目标利用EGO-Planner进行动态路径规划，根据环境障碍物及封控智能体的实时位置在线调整运动路径，尽可能延长其在区域内未被捕获的时间。
入侵目标可以是无人机或无人车。其主要运动参数包括：

\begin{itemize}
    \item 最大线速度与最大角速度；
    \item 当前线速度与当前角速度。
\end{itemize}


\subsection{协同封控流程}

系统的协同封控流程如下：

\begin{enumerate}
    \item 光电云台、无人机和麦轮车按照各自的巡检策略执行区域搜索任务；
    \item 当入侵目标进入任一智能体的感知范围并被成功识别后，该智能体立即将目标的位置、速度等状态信息发送至其他智能体；
    \item 所有封控智能体同时切换至捕获模式，并根据目标状态和环境信息进行协同围捕；
    \item 无人机与麦轮车分别对入侵目标进行追踪、拦截和包围；
    \item 当入侵目标与任一无人机之间的距离不大于 $r_1$，或与麦轮车之间的距离不大于 $r_2$ 时，判定该目标被成功捕获，围捕任务结束。
\end{enumerate}
\section{无人机状态估计：SWARM-LIO 集群激光-惯性紧耦合里程计与动捕系统融合}

\subsection{概述}

系统采用~\textbf{FAST-LIO2}作为状态估计模块~\cite{xu2022fastlio2}，FAST-LIO2~是一种紧耦合的迭代扩展卡尔曼滤波激光-惯性里程计算法，无需特征提取，直接将去畸变后的原始激光点通过点到平面距离残差与~ikd-Tree~地图配准，实现高精度、低延迟的~6~自由度位姿估计。

系统中，IMU~数据来源于飞控内置的双~BMI-088~传感器，以~$200\,\text{Hz}$~频率输出加速度与角速度测量。LiDAR~与~IMU~之间的外参及时间偏移采用~LI-Init~\cite{zhu2022liinit}离线标定得到，标定后里程计以~IMU~坐标系为参考基准。

\subsubsection{入场和逃逸（以一种双车入侵为例）}
\begin{itemize}
\item \texttt{car2} 从左侧入口进入；
\item \texttt{car3} 从右侧入口进入；
\item 入侵车进入 $6\,\mathrm{m}$ 正方形前按 launch 中的 \texttt{intruder\_routes} 行驶；
\item 入侵车进入后，以自身有界 Voronoi 元胞质心方向生成逃逸目标；
\item 追捕者优先前往与入侵车相邻的共享 Voronoi 边中点；若不相邻，则追向最近的活动入侵车；
\item 所有目标被限制在边界内，并保留 \texttt{target\_margin}。
\end{itemize}
\subsubsection{捕获判据}
对每辆已进入房间的活动入侵车，计算其与四个追捕者的二维平面距离：

\begin{equation}
d_i = \sqrt{(x_i-x_{\mathrm{evader}})^2+(y_i-y_{\mathrm{evader}})^2}
\end{equation}

满足以下条件即捕获：

\begin{equation}
\min_i d_i \leq d_{\mathrm{capture}}
\end{equation}

当前 launch 默认 $d_{\mathrm{capture}}=0.5\,\mathrm{m}$。捕获后：
\begin{enumerate}
\item 发布捕获者、实际距离和该入侵车入场后的捕获用时；
\item 将被捕获车辆移动到场景外 $(x\approx100, y=100, z=-10)$，不直接删除
\texttt{ros\_control} 模型，以避免 \texttt{gzserver} 死锁；
\item 若仍有另一辆入侵车，继续追捕；
\item 所有入侵车捕获后停止两辆追捕车，并让两架 UAV 进入 HOVER。
\end{enumerate}

\subsection{实验结果分析与未来可改进点}
\begin{itemize}
\item 当前围捕没有避障逻辑，并且包围和捕获之间没有明确界限。后续为Voronoi围捕增加避障逻辑，更加贴合货物大量堆积的仓库场景;或者改成另外一种同样基于Voronoi的围捕分离的OA算法。
\item 中心化通信对地面站通信压力大，后面考虑改成基于B.A.T.M.A的分布式通信，减少对地面站的依赖
\item 目前无人机和无人车的速度差异较大，后续考虑增加无人机的速度限制，或者增加无人车的速度
\end{itemize}
