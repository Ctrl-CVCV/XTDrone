# 无人机与车辆可调参数清单（两车两机围捕一机）

> 按智能体类型分开列出全部可调参数。来源标注了文件位置：
> - `air_intruder_mission.yaml`：围捕任务参数（宿主与容器同文件）
> - `nav_to_pose_params.yaml`：车辆三阶段导航参数（`car3_control/params/`）
> - 容器内文件：EGO 规划器 / 起飞脚本等（**不在宿主 workspace**，需容器内改）
>
> 生效方式见每节"生效"说明。

---

## 一、无人机（iris_0 / iris_1 / iris_2）

### 1.1 飞行高度

| 参数 | 默认 | 位置 | 说明 |
|---|---|---|---|
| `uav.fixed_altitude` | 1.33 | air_intruder_mission.yaml | 三机统一恒高 H_f，**必须 < 3m 墙**。生效：重启 pursuit 节点 |

### 1.2 飞行速度 / 加速度（EGO 规划器，**容器内文件**）

| 参数 | 默认 | 位置 | 说明 |
|---|---|---|---|
| `max_vel` | 0.5 | `/home/dev/ego_ws/src/ego_planner/plan_manage/launch/run_in_xtdrone.launch` | 无人机最大飞行速度 (m/s)。调大=追得快但更容易过冲/撞墙；调小=更稳但围捕慢 |
| `max_acc` | 1.0 | 同上 | 最大加速度 (m/s²)。调大=加减速更猛 |

> 该文件在容器镜像内（非宿主挂载），改法：
> ```bash
> docker exec xtdrone-dev-gpu sed -i 's/value="0.5"/value="0.7"/' /home/dev/ego_ws/src/ego_planner/plan_manage/launch/run_in_xtdrone.launch
> docker exec xtdrone-dev-gpu sed -i 's/value="1.0"/value="1.5"/' /home/dev/ego_ws/src/ego_planner/plan_manage/launch/run_in_xtdrone.launch
> ```
> 生效：**重启仿真**（ego_planner 启动时读取）。

### 1.3 起飞相关

| 参数 | 默认 | 位置 | 说明 |
|---|---|---|---|
| `--altitude` | 1.5 | uav_offboard_takeoff.py 命令行 | 起飞高度，一键脚本默认 1.33（=H_f）。 |
| `MPC_LAND_CRWL` | 2.0 | uav_offboard_takeoff.py 常量 `LAND_CRWL_VALUE` | 地检垂向运动阈值调参，**解决起飞 0 推力问题**。一般勿动；若起飞又失败可适当再调大。 |

### 1.4 阵型 / 封堵（围捕阶段，air_intruder_mission.yaml）

| 参数 | 默认 | 作用 |
|---|---|---|
| `formation.uav_forward_offset` | 1.5 | 宽松阵型 UAV 前方距离 |
| `formation.uav_lateral_offset` | 2.0 | 宽松阵型 UAV 横向展开 |
| `formation.uav_margin` | 0.8 | UAV 目标贴墙收缩余量（防撞墙关键） |
| `formation.encircle_uav_forward` | 0.4 | 紧阵型 UAV 前方距离 |
| `formation.encircle_uav_lateral` | 0.6 | 紧阵型 UAV 横向展开 |
| `gate_seal.trigger_dist` | 1.8 | 触发封堵的距离阈值 |
| `gate_seal.inset` | 1.0 | 堵头 UAV 向墙推进距离 |
| `gate_seal.dwell` | 1.5 | 封堵侧停留时间 |
| `gate_seal.heading_cos` | 0.3 | 朝墙飞才封堵的方向阈值 |

生效：重启 pursuit 节点。

### 1.5 固定朝向（非数值调参，说明）

桥（`multirotor_communication.py`）捕获每机**出生世界 yaw**，全程用 `hold_yaw()` 锁死朝向（iris_0/1 保持 0°、iris_2 保持 -90°）。机动瞬时偏差 ~±16° 后自动回稳。无公开调参接口。

### 1.6 与无人机直接相关的捕获判定

| 参数 | 默认 | 位置 | 作用 |
|---|---|---|---|
| `capture.air_capture_radius` | 1.8 | air_intruder_mission.yaml | 两架 UAV 均须距 iris_2 < 该值才参与判定 |

## 二、车辆（car0 / car1）

> **重要**：当前围捕场景的小车用**自研三阶段 nav_to_pose**（`nav_to_pose_node`）驱动，直接读 `/scan` 势场避障，**不使用** DWA/move_base，也不使用 global/local costmap。因此 `dwa_local_planner_params.yaml`、`costmap_common_params.yaml` 等**当前不生效**（历史遗留）。车辆实际生效参数见下方 `nav_to_pose_params.yaml`。

### 2.1 速度与加减速（`car3_control/params/nav_to_pose_params.yaml`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `max_vel_trans` | 1.0 | 最大平移速度 (m/s)。调大=追得快；调大易过冲，且靠近 iris_2 时更难收住 |
| `max_vel_theta` | 2.0 | 最大旋转角速度 (rad/s) |
| `acc_lim_trans` | 2.0 | 平移加速度限制 |
| `acc_lim_theta` | 2.0 | 旋转加速度限制 |
| `kp_trans` | 1.2 | 距离→速度比例增益（越大越贴目标，过快易抖动） |
| `kp_rot` | 2.5 | 角度误差→角速度比例增益 |
| `slow_radius` | 0.6 | 进入该半径内线性减速 (m) |

生效：**重启仿真**（nav_to_pose 启动时加载）。

### 2.2 到位与姿态容差（同文件）

| 参数 | 默认 | 说明 |
|---|---|---|
| `goal_radius` | 0.18 | 到达目标判定半径 (m)。捕获时小车目标贴机下，调大=更易到位但更不贴 |
| `goal_radius_exit` | 0.35 | 漂出该半径回退平移（滞回，防抖） |
| `goal_yaw_tolerance` | 0.08 | 终态朝向容差 (rad) |
| `goal_yaw_start_tolerance` | 0.25 | 朝向重新转动的宽阈值 |
| `align_tolerance` | 0.08 | ALIGN 阶段朝向窄阈值 |
| `align_start_tolerance` | 0.25 | ALIGN 重新转动宽阈值 |
| `settled_cycles` | 5 | 连续满足容差的周期数才切换阶段 |

### 2.3 避障与逃逸（同文件）

| 参数 | 默认 | 说明 |
|---|---|---|
| `repulse_range` | 0.6 | 障碍物进入该距离开始排斥 (m) |
| `repulse_gain` | 0.8 | 排斥力占 max_vel_trans 的比例 |
| `escape_angle` | 0.3927 | 前方扇形半角（22.5°，总 45°）；扇形内有障碍触发横向逃逸 |
| `escape_range` | 0.30 | 触发逃逸的障碍距离 |
| `escape_resume_clear` | 0.6 | 逃逸结束判定：前方扇形清空到该距离 |
| `escape_speed` | 0.25 | 横向逃逸速度 |
| `escape_stuck_time` | 3.0 | 横向位移窗口（低于 escape_min_progress 判卡住→切左） |
| `escape_max_time` | 8.0 | 逃逸最长时长，超时强制结束/切向 |
| `escape_min_progress` | 0.08 | 逃逸最小有效位移 (m) |
| `stall_time` | 20.0 | 无进展判定窗口 (s)，超时中止目标 |
| `stall_min_progress` | 0.08 | 无进展的最小位移阈值 |

> 这些决定小车能否在拥挤的内区里贴着阵型点避开车/墙移动。内区约 6m 见方，**默认 1.0 m/s 较快**，若小车在紧阵型下超调/撞墙，优先调小 `max_vel_trans` 和调大 `slow_radius`。

### 2.4 阵型（air_intruder_mission.yaml）

| 参数 | 默认 | 作用 |
|---|---|---|
| `formation.ugv_rear_offset` | 1.2 | 宽松阵型 UGV 后方距离 |
| `formation.ugv_lateral_offset` | 2.0 | 宽松阵型 UGV 横向展开 |
| `formation.ugv_margin` | 0.4 | UGV 目标贴墙收缩余量 |
| `formation.encircle_ugv_lateral` | 0.3 | 紧阵型 UGV 贴投影两侧 ± |
| `capture.ground_projection_radius` | 0.5 | 两车均须距投影 < 该值 |

生效：重启 pursuit 节点。

### 2.5 出生位姿（multi_vehicle.launch 参数，容器内）

| 参数 | 默认 | 位置 |
|---|---|---|
| `car0_x / car0_y / car0_yaw` | 2.3 / 2.4 / -2.334 | `/home/dev/PX4-Autopilot/launch/multi_vehicle.launch` |
| `car1_x / car1_y / car1_yaw` | -2.3 / -2.4 / 0.808 | 同上 |

### 2.6 定位（`car3_control/params/amcl_params.yaml`）

AMCL 定位参数（初始位姿在 launch 中由 car0_x/y 等注入）。一般不动，若小车位姿漂移可查。

### 2.7 轮速 PID（低层，一般不动）

| 文件 | 内容 |
|---|---|
| `car3_control/config/car3_controllers.yaml` | 四轮速度控制器 PID（p=1.0） |
| `car3_control/config/gazebo_pid.yaml` | Gazebo 轮关节 PID（p=0.15, d=0.00002） |

轮速跟踪层，出现"轮子打滑/响应慢"才考虑调。

## 三、对照速查表

| 想调什么 | 改哪 | 生效方式 |
|---|---|---|
| 无人机飞多高 | `uav.fixed_altitude`（yaml） | 重启 pursuit |
| 无人机飞多快 | EGO `run_in_xtdrone.launch` max_vel/max_acc（容器内） | 重启仿真 |
| 无人机阵型贴身程度 | `formation.uav_forward_offset`/`encircle_uav_forward` 等（yaml） | 重启 pursuit |
| 无人机贴墙/撞墙 | `formation.uav_margin`（yaml） | 重启 pursuit |
| 小车追多快 | `nav_to_pose_params.yaml` `max_vel_trans`/`acc_lim_trans` | 重启仿真 |
| 小车避障灵敏度 | `nav_to_pose_params.yaml` repulse_*/escape_* | 重启仿真 |
| 小车阵型/贴机下 | `formation.ugv_*` / `encircle_ugv_lateral`（yaml） | 重启 pursuit |
| 捕获难易 | `capture.air_capture_radius`/`ground_projection_radius`/`hold_time`（yaml） | 重启 pursuit |
| 封堵防逃逸 | `gate_seal.*`（yaml） | 重启 pursuit |
