## 1. 坐标系与基本概念

- 所有战术计算用 **Gazebo 世界系 XY**；入侵机 iris_2 恒高 H_f=1.33m，防御 UAV 同高，车辆在地面。
- **内区** = 3m 内墙包围的净区（`inner_region`：x∈[-3.09,2.86]，y∈[-2.98,2.97]）。入侵 = iris_2 的 XY 进入内区；逃逸 = 离开内区。
- 每次计算阵型前，先求 iris_2 的**逃逸方向 e** 和与它垂直的**法向 n**（n = e 逆时针转 90°）。

## 2. 两种阵型详解

### 2.1 宽松阵型（PURSUIT 阶段）

**什么时候用**：入侵检测触发后、包围形成前的"追捕"阶段。

**几何定义**（相对 iris_2 位置 pE）：

```
           e ↑（iris_2 逃逸方向）
     ┌──────────────────────────────┐
     │                              │
     │   uav_left(前方1.5,左2.0)    │  uav_right(前方1.5,右2.0)
     │            \        /        │
     │             \  pE  /         │
     │              iris_2          │
     │            /        \        │
     │   ugv_left(后方1.2,左2.0)    │  ugv_right(后方1.2,右2.0)
     │                              │
     └──────────────────────────────┘
```

```
uav_left  = pE + uav_forward_offset·e + uav_lateral_offset·n     （1.5 / 2.0）
uav_right = pE + uav_forward_offset·e − uav_lateral_offset·n
ugv_left  = pE − ugv_rear_offset·e   + ugv_lateral_offset·n      （1.2 / 2.0）
ugv_right = pE − ugv_rear_offset·e   − ugv_lateral_offset·n
```

**分工逻辑**：
- **UAV 在逃逸方向前方两翼** → 迎面拦截、封住前进路线；
- **UGV 在逃逸方向后方两翼** → 挡住掉头逃逸的退路；
- 前后夹击形成"口袋"，迫使 iris_2 无路可走。

**为什么要"宽松"**：追捕阶段距离还远，需要较宽的口袋先兜住，太贴身会惊到 iris_2 提前转向冲出包围。

### 2.2 紧阵型（ENCIRCLED 阶段）

**什么时候用**：四追捕者凸包已把 iris_2 包住（`_encircled_check` 通过）后，进入收缩逼近阶段。

**几何定义**（新增参数 encircle_*）：

```
             uav_left(前方0.4,左0.6)     uav_right(前方0.4,右0.6)
                       \      ↑      /
                        \   iris_2  /
                         \   pE    /
                    car0   (机下)   car1
                  贴投影左侧±0.3m    贴投影右侧±0.3m
```

```
uav_left  = pE + encircle_uav_forward·e + encircle_uav_lateral·n   （0.4 / 0.6）
uav_right = pE + encircle_uav_forward·e − encircle_uav_lateral·n
ugv_left  = pE + encircle_ugv_lateral·n                            （±0.3）
ugv_right = pE − encircle_ugv_lateral·n
```

**与宽松阵型的差异**：
1. 尺寸缩小（前方 1.5→0.4、横向 2.0→0.6），阵型收紧压向 iris_2；
2. **小车不再留在后方**，而是直接贴到 iris_2 地面投影两侧 ±0.3m —— 用户要求的"捕获时小车在入侵机正下方"，与捕获判定 R_g=0.5 匹配；
3. 封堵功能在紧阵型下**禁用**（阵型本身已封口，再封堵会拆散包围圈）。

**为什么**：包围已形成，目标是把距离压到捕获半径内并保持，让双 UAV 和双 UGV 同时达标。

### 2.3 边界门封堵（gate_seal，仅宽松阵型）

iris_2 逼近某条内墙（≤1.8m）**且**逃逸方向朝该墙（夹角阈值）时，抽一架 UAV 到 iris_2 与墙之间的"影子"位，堵住它朝门口冲的逃路，同时把 Voronoi 逃逸质心拉回内区中央、放慢逃跑。

```
墙 ███████████████
    ├─── inset 1.0 ──►
    UAV堵头(停在墙内0.8m) ←——— iris_2  ←———（离墙>1.8m 就不封堵）
```

## 3. 参数详解（air_intruder_mission.yaml）

### 3.1 `uav` —— 无人机统一高度

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `fixed_altitude` | 1.33 | 三机统一恒高 H_f。**必须 < 墙高 3.0**（低于 3m 墙，UAV 不能越墙，因此阵型目标必须收在边界内）。调高会更接近墙顶、更能"俯瞰"，但接近 3m 会与虚拟墙碰撞逻辑冲突。 |
| `wall_height` | 3.0 | 内墙真实高度，仅用于越墙判定日志；一般不动。 |

### 3.2 `intruder` —— iris_2 出生与入侵路线

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `spawn_mode` | fixed | `fixed`=按 `fixed_corner` 出生；`random`=随机两角（复现需 `random_seed`）。 |
| `fixed_corner` | CORNER_1 | 固定左下角外墙 (-5,-5)，yaw -π/2 朝 DOWN 门。 |
| `spawn_corner_0/1` | [x,y,yaw] | 两角的世界坐标与出生朝向。第三元是出生 yaw（-π/2 = 朝南/DOWN）。 |
| `entry_mode` / `entry_side` | fixed / UP | 入侵方向门。**当前只有与出生角相邻的方向可用**（CORNER_1 有效 DOWN/LEFT；跨角方向需走廊路由）。注意：`entry_mode` 当前节点未真正使用，直接改 `entry_side`。 |
| `random_seed` | 0 | `spawn_mode=random` 时的随机种子；节点未读取（预留）。 |
| `approach_offset` | 1.2 | 墙外待机点距墙段中心线的距离（门外侧）。 |
| `inside_offset` | 1.2 | 穿墙后内点距墙段中心线的距离。 |
| `entry_arrive` | 0.4 | 阶段到位判定半径：距目标 < 0.4m 视为到达。 |
| `approach_settle` | 1.2 | 待机点最短停留秒数，配合停稳判定。 |
| `entry_speed_eps` | 0.1 | 进墙内目标前允许的最大水平速度；**停稳判定阈值**。调大=更快进门但易带横移动量偏出门洞。 |
| `entry_speed_hold` | 0.4 | 速度需持续低于 eps 的时长。 |
| `entry_speed_cap` | 6.0 | 停稳等待上限，超时强制进门（防悬停抖动永不达标卡死）。 |
| `approach_pre_extra` | 2.0 | 门洞中心线预对齐点额外外推距离，消除 EGO 重规划的横向偏置。 |
| `over_wall_check_z` | 3.3 | 飞越判定高度阈值；**当前节点未读取**（预留）。 |
| `evasion_min_speed` | 0.5 | 逃逸方向取速度方向的最低速度；低于则退化为"朝元胞质心"。调小=更多用真实速度方向（更激进）。 |
| `evasion_cell_margin` | 0.1 | Voronoi 逃逸目标相对内区边界的收缩余量。 |

### 3.3 `formation` —— 阵型几何（本次调参核心）

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `uav_forward_offset` | 1.5 | **宽松阵型** UAV 在逃逸方向前方的距离。调大=口袋更远更大、给 iris_2 更多活动空间；调小=追得更贴身。 |
| `uav_lateral_offset` | 2.0 | **宽松阵型** UAV 横向展开距离。调大=两翼更宽、封口更宽但空隙大；调小=两翼更窄、更容易夹住但易被从侧翼突破。 |
| `ugv_rear_offset` | 1.2 | **宽松阵型** UGV 在投影后方的距离。调大=退得更后（留更大尾部空间）。 |
| `ugv_lateral_offset` | 2.0 | **宽松阵型** UGV 横向展开距离。 |
| `ugv_margin` | 0.4 | UGV 阵型点相对内区边界的收缩余量。调大=小车更不敢贴墙（防挤墙）。 |
| `uav_margin` | 0.8 | UAV 目标相对内区边界的收缩余量。**防 EGO 过冲撞墙的关键**：H_f=1.33 < 3m 墙，UAV 目标贴墙会被 EGO 规划撞墙。调大=更远离墙（更安全但封口弱）；调小=更贴墙（封口强但易撞墙）。 |
| `encircle_uav_forward` | 0.4 | **紧阵型** UAV 前方距离。调小=收得更贴 iris_2（更快达标，但空间小易碰撞）。 |
| `encircle_uav_lateral` | 0.6 | **紧阵型** UAV 横向展开。调小=两翼更贴近，捕获半径更易满足。 |
| `encircle_ugv_lateral` | 0.3 | **紧阵型** UGV 贴投影两侧距离（±）。调小=小车更贴机下（但易两车重叠）；**必须与 R_g 匹配**（±0.3 → R_g≥0.5 合适）。 |

### 3.4 `capture` —— 捕获判定

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `air_capture_radius` | 1.8 | R_c：**两架** UAV 距 iris_2 的 XY 距离都须 < 该值（取最远一架 uav_max 判）。调小=捕获更严（更难达成）；调大=更宽松。 |
| `ground_projection_radius` | 0.5 | R_g：**两辆** UGV 距 iris_2 地面投影都须 < 该值。调小=要求小车贴得更死。 |
| `hold_time` | 2.0 | 捕获条件需持续保持的秒数，防瞬时达标误捕获。 |
| `encircle_min_area` | 0.5 | 凸包面积下限，避免四追捕者近共线（贴成一条线）误判包围。 |
| `encircle_margin` | 0.3 | 包围判定边界余量：iris_2 距凸包边界 < 该值也算包围，防边界振荡清零捕获计时。 |

### 3.5 `gate_seal` —— 门封堵

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `enabled` | true | 总开关。关掉后 iris_2 逼近墙边时不会有 UAV 去封堵。 |
| `trigger_dist` | 1.8 | iris_2 距某条边界 < 该值时触发封堵。调大=更早封堵（更稳但 UAV 常被调走）；调小=更晚（iris_2 更接近逃逸点，风险高）。 |
| `inset` | 1.0 | 堵头 UAV 自 iris_2 沿指向墙方向推进的距离。调大=堵得更贴墙。 |
| `dwell` | 1.5 | 封堵侧承诺停留秒数：期间不随 iris_2 摆动切换侧，防堵头目标大跳变。 |
| `heading_cos` | 0.3 | 只有逃逸方向与墙外法向点积 ≥ 该值（明显朝墙飞）才封堵，避免无谓调位。调大=只对很正的朝墙飞封堵。 |

### 3.6 `planning` —— 目标发布节流

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `tactical_rate` | 15.0 | 战术/判定循环频率（Hz）。 |
| `goal_publish_rate` | 3.0 | 实际目标发布上限频率。**别调太高**：高频刷新 EGO goal 会导致规划抖动。 |
| `goal_change_threshold` | 0.3 | 目标位移达该值才重新发送（m）。调小=目标更灵敏跟随 iris_2。 |
| `re_goal_interval` | 5.0 | 目标不变但智能体未到位时的周期重发（s）。 |

### 3.7 `fsm` —— 状态机时序

| 参数 | 默认 | 含义与调参影响 |
|---|---|---|
| `intrusion_debounce` | 0.3 | outside→inside 去抖秒数，之后触发入侵警报。 |
| `staging_wait` | 1.0 | STAGING 阶段停留确认时间；**节点当前未读取**（预留）。 |
| `auto_start` | true | 就绪后自动开始任务。false 需调 `/air_intruder/pursuit/start` 服务。 |
| `start_delay` | 1.0 | 就绪后附加延迟（s）。 |
| `encircle_fallback_delay` | 1.5 | 紧阵型丢失包围持续该值后回退宽松阵型重新封堵（s）。调大=更耐包围损失；调小=更快回退补救。 |

### 3.8 `inner_region` / `gate_positions` / `gate_normals`

内区包围盒与四门中心/法向，直接取自 nesting_room 实测，**只读，不建议改动**（改错会导致入侵/逃逸判定错乱）。

## 4. 常见调参组合思路

| 现象 | 优先调整 |
|---|---|
| 捕获太难（老差一点） | 调大 `capture.air_capture_radius` / `ground_projection_radius`；或调小 `encircle_uav_forward`/`encircle_uav_lateral` 让 UAV 收得更贴 |
| UAV 撞墙 / 贴墙 | 调大 `formation.uav_margin`（0.8→更大）；调大 `gate_seal.inset` 的墙内余量由 uav_margin 决定 |
| iris_2 从门口逃逸 | 调小 `gate_seal.trigger_dist`（更早封堵）；调大 `gate_seal.inset`；调小 `uav_margin`（更贴墙封口，但注意撞墙风险） |
| 围捕太松散、追不上 | 调小宽松阵型的 `uav_forward_offset`/`ugv_rear_offset`（口袋收紧） |
| 小车被挤在墙边 | 调大 `formation.ugv_margin` |
| 想缩短捕获耗时 | 调小 `capture.hold_time`（但更易瞬时误捕获） |
| 捕获条件一闪就破 | 调大 `capture.hold_time`、调大 `capture.encircle_margin` |
